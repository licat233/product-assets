# Agent Rules

This repository is a controlled product source-of-truth and public asset origin.

- Do not invent product facts.
- Preserve the four evidence classes in every product file: confirmed, observed, inferred, unknown/do-not-claim.
- Do not move internal metadata into `public/`.
- Do not replace authoritative source photos with AI-generated images.
- Do not add frameworks, databases, asset pipelines, image optimization services, or build dependencies unless explicitly approved.
- Prefer semantic lowercase kebab-case filenames.
- When editing an existing product, make the smallest factual change supported by evidence.
- Keep `assets_base_url` stable unless the hosting architecture is intentionally migrated.
