# ChatGPT + DetailFlow Usage

After the repository is connected to ChatGPT's GitHub access and `assets.licat.xyz` is live, a new session can be started with a short request.

## Recommended prompt

```text
Use DetailFlow to create an 8-screen English ecommerce detail page for product:
rechargeable-led-sensor-light

Product repository:
licat233/product-assets

Before planning, read:
- products/rechargeable-led-sensor-light/product.md
- products/rechargeable-led-sensor-light/manifest.yaml
- all referenced product images in the manifest

Treat Confirmed facts as authoritative, Directly observed facts as visual evidence, Reasonable creative inferences as unconfirmed, and Unknown / do not claim as prohibited unless I provide new evidence.

Follow DetailFlow's standard two approval gates strictly.
Do not generate final images before I approve the 8-screen blueprint.
All visible commercial copy must be English unless I say otherwise.
```

## Short form

Once the workflow is established, this is normally enough:

```text
Use DetailFlow for `rechargeable-led-sensor-light` from `licat233/product-assets`.
Read its product.md, manifest and image references first. English overseas-market page. Follow both approval gates.
```
